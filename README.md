# DigiAssist AI

DigiAssist AI is a hackathon prototype that simulates a consent-based DigiLocker connection and helps citizens understand whether their documents are ready for common applications.

## What it demonstrates

- Simulated DigiLocker connection (no real personal data or OTP)
- Ten fictional issued-document records
- Fourteen common services including passport, scholarship, banking, education, transport and public benefits
- Readiness scoring based on mandatory requirements
- Accepted alternatives for identity, address and date-of-birth proof
- Separate handling for verified, expired, optional, external-upload and missing documents
- Responsive desktop and mobile interface

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Important

This is an unofficial demonstration project. It is not connected to DigiLocker, UIDAI, or any government production system. All displayed personal and document data is fictional.
